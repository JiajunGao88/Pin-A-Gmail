# Gmail 邮件置顶扩展

一个简单但实用的 Chrome 扩展，为 Gmail 网页版添加邮件置顶功能。

## 功能特点

- 📌 在邮件列表中添加置顶按钮
- ⚡ 一键置顶/取消置顶邮件
- 💾 自动保存置顶状态
- 🔄 支持页面动态刷新
- ✨ 平滑的动画效果

## 安装方法

1. 下载此仓库的所有文件
2. 打开 Chrome 浏览器，进入扩展管理页面 (`chrome://extensions/`)
3. 开启右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择包含扩展文件的文件夹

## 使用说明

1. 安装扩展后，打开 Gmail 网页版
2. 在邮件列表中，每封邮件前会出现一个📌图标
3. 点击📌图标可以置顶/取消置顶该邮件
4. 置顶的邮件会自动移动到列表顶部
5. 置顶状态会自动保存，重新打开浏览器后依然有效

## 技术实现

- 使用 Chrome Extension Manifest V3
- 通过 MutationObserver 监听 Gmail 界面变化
- 使用 Chrome Storage API 持久化存储置顶状态
- CSS 动画实现平滑的视觉效果
- 防抖处理优化性能


## 注意事项

- 仅支持 Gmail 网页版
- 需要 Chrome 浏览器版本 88 或更高
- 置顶功能仅在当前邮箱视图中生效
- 不会影响邮件本身的内容和状态

## 隐私说明

- 本扩展不会收集任何用户数据
- 所有置顶状态仅保存在本地浏览器中
- 不会与任何外部服务器通信
